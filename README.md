# MoneyMate LINE Bot — Shared Expense Pro

LINE bot สำหรับรายรับรายจ่าย + บัญชีร่วม + หารค่าใช้จ่ายแบบเท่ากัน/เปอร์เซ็นต์/จำนวนเงิน + settlement อัตโนมัติ

## ตัวอย่างการใช้
- `กินข้าว 120`
- `ค่าไฟ 1200 หารครึ่ง`
- `ค่าไฟ 1200 ฉัน 40% แฟน 60%`
- `กินข้าว 1200 ฉัน 400 แฟน 800`
- `ฉันจ่ายไปก่อน เดี๋ยวแฟนคืนครึ่งนึง` → ใช้คู่กับการระบุยอดและระบบหารครึ่ง
- `สรุปค่าใช้จ่ายร่วม` → แสดงว่าใครจ่ายเกิน/ขาด และคำนวณรายการโอนที่สั้นที่สุด

## รูปแบบการหาร
- `self` = คนจ่ายรับผิดชอบเต็มจำนวน
- `equal` = แบ่งเท่ากันทุกคนในบัญชีร่วม
- `percent` = ระบุสัดส่วน เช่น `ฉัน 40% แฟน 60%`
- `custom` = ระบุจำนวนเงิน เช่น `ฉัน 400 แฟน 800`

ระบบเก็บ `payer_user_id`, ผู้ร่วมรายการ และจำนวนที่แต่ละคนรับผิดชอบในแต่ละ transaction

## Settlement
ตัวอย่างผลลัพธ์:
- แก้ว จ่าย ฿2,000 / รับผิดชอบ ฿1,000 → ควรได้รับ ฿1,000
- บี จ่าย ฿0 / รับผิดชอบ ฿1,000 → ควรจ่าย ฿1,000
- ระบบจะแนะนำ: `บี → แก้ว ฿1,000`

## Environment
ดู `.env.example` สำหรับ `LINE_CHANNEL_SECRET`, `LINE_ACCESS_TOKEN`, `OPENAI_API_KEY`, `PUBLIC_URL`, `DATABASE_PATH`
